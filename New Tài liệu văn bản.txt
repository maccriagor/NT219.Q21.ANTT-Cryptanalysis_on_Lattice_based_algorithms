# Mục tôi **THÊM** (không có trong 05 nhưng cần để "đúng học thuật")

3 chỉnh sửa này **không phải từ file 05** — tôi đề xuất thêm vì file 05 viết ở thời điểm trước chuẩn hoá hoặc dùng giả định kỹ thuật đã lỗi thời. Bạn cần ghi nhận rõ:

| Mục thêm | Lý do (KHÔNG ở file 05) |
|---|---|
| **Đổi tên Kyber→ML-KEM (FIPS 203), Dilithium→ML-DSA (FIPS 204)** | File 05 (§5–7) dùng tên cũ "Kyber/Dilithium". Sau 13/08/2024 NIST chuẩn hoá tên mới, bản FIPS-final khác *nhẹ* round-3. Nếu giữ tên cũ → mất điểm academic correctness. |
| **OpenSSL ≥ 3.5 native thay "OpenSSL-OQS fork"** | File 05 §7.2 và §16 đề xuất "OpenSSL OQS fork" — fork đã deprecated; OpenSSL 3.5 (4/2025) hỗ trợ ML-KEM/ML-DSA native + nhóm hybrid. |
| **`rdtsc`/`cntvct_el0` ≠ core cycles** khi DVFS/turbo bật | File 05 §7.5 yêu cầu *"fix CPU frequency (disable turbo), isolate cores"* nhưng không nói rõ giới hạn của TSC/virtual timer. Cần dùng `perf stat` hoặc PMU thuần để có cycle thật. |
